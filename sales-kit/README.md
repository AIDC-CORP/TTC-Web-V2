## 📁 CẤU TRÚC THƯ MỤC SALES KIT

```
sales-kit/
├── README.md                           # Thư mục chính & Hướng dẫn sử dụng
├── 01-capability-statement/            # 1. Capability Statement (2 trang) - Teaser Sheet
├── 02-corporate-brochure/              # 2. Corporate Brochure (8 trang) - Ấn phẩm Triển lãm
├── 03-executive-profile/               # 3. Executive Profile (12 trang) - Bản C-Level
├── 04-presentation-pitchdeck/          # 4. Presentation PowerPoint (25 slide) - Pitch Deck
├── 05-company-profile/                 # 5. Master Company Profile (60 trang) - Hồ sơ thầu gốc
└── 06-project-portfolio/               # 6. Project Portfolio (100-150 trang) - Lookbook dự án
```

---

## 🛠️ QUY TRÌNH BIÊN SOẠN & DUYỆT NỘI DUNG (WORD -> PDF)

1. **Giai đoạn 1 (File .md / .docx cho Sếp duyệt):** Soạn thảo bản chữ đầy đủ thông tin, cấu trúc rõ ràng trong từng thư mục tương ứng.
2. **Giai đoạn 2 (Dàn trang đồ họa & Xuất PDF):** Sau khi Sếp duyệt nội dung, chuyển sang dàn trang HTML/Tailwind/InDesign để xuất file PDF chuẩn đồ họa như bản mẫu Hợp Lực & Reecons.
